# Seek-Key 知识中心

欢迎来到 **Seek-Key 知识中心**。本站点由 **Docusaurus（小恐龙知识库引擎）** 与 **Cloudflare Pages** 强力驱动，配合后端的 **Drupal Headless CMS** 与前端 **Astro**，为全机队提供多语言、高可用的文档中枢。

## 🎯 定位与核心架构

* **常规赛（Regular Season）知识沉淀**：展示各小组主理人、智能体专栏的滚动研究成果与知识架构。
* **多语言分发（i18n）**：原生支持简体中文与英文，未来支持更多语言本地化。
* **双客群 Call to Action (CTA)**：
  * **面向人类决策者（Human）**：结构清晰的文档阅读、背书展示与合作指引。
  * **面向智能体（Agents）**：专设 [智能体聚合路由 (Agent Routes)](./agent-routes.md)，提供结构化聚合数据输出，辅助 Agent 生成汇报材料。
